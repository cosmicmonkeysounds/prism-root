Lesson 03 — writing dialogue

Dialogue is the heart of any script. In Loom it looks almost exactly like a screenplay: a SPEAKER name on its own line, with the words underneath indented two spaces.

The basic shape

WREN
  The bell went silent three days ago.

That's a complete dialogue beat. Two things make it work:

  • The speaker name is ALL CAPS. Loom uses the all-caps convention to recognise speaker lines without you marking them.
  • The line beneath is indented by exactly two spaces. The indent tells Loom "this belongs to Wren".

Multi-line dialogue

A character can speak for several lines. Keep them at the same indent and Loom plays them as one continuous beat. 

WREN
  The bell went silent three days ago.
  Nobody has been up to the tower since.
  I'm asking you to look.

Parentheticals

Tucked between the speaker and the dialogue, parentheticals tell the actor how a line is delivered. Loom writes them with curly braces. 

WREN { worried }
  The bell went silent three days ago.

WREN { whispering, urgent }
  Don't look up.

You can stack multiple parentheticals (comma-separated). Common ones are quiet, warm, wary, angry, resigned — whatever your project needs. They're free-form labels; what matters is that they read naturally to your performer.

Two characters in a row

To alternate speakers, write each one's name on its own line with dialogue underneath. A blank line between beats is optional but helps readability. 

WREN
  Are you new here?

ALEX
  Just got in yesterday.

WREN { laughing }
  It shows.

What you just learned

  • SPEAKER on a line by itself + indented text below = one dialogue beat.
  • Multiple indented lines under the same SPEAKER = a multi-line beat.
  • SPEAKER { tone } is the parenthetical. Multiple tones go in a comma-separated list.
  • Alternating speakers is just: one block after another.
