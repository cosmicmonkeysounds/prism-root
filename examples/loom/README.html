Loom writer's tour

Loom is a language for writing stories that branch, react, and play. It looks like a screenplay, runs like a program, and reads like a script you could hand to a stage manager. This folder is a hands-on tour — start at the top, open each lesson in order, read the page, then open the .loom file next to it.

You don't need to know how to code. If you've ever written a letter, a dialogue, or a play, you already know most of what's here. The few programming-shaped pieces (variables, conditions) are introduced one at a time and always demonstrated in a working story.

Before we begin: what is a screenplay?

If you've written for theatre or film before, skip ahead. If not — here's the whole thing in 30 seconds.

A screenplay (or stage script) is a written plan for a performance. It tells three kinds of people what to do:

  • Performers — what to say and how to say it.
  • The crew — when lights change, when music plays, what the set looks like.
  • The audience — implicitly, through what they hear and see.

In a traditional screenplay every line carries one of a few labels — a scene heading, an action line, a character name, a parenthetical, or a line of dialogue. Layout matters: character names are centered and capitalised, dialogue is indented under them, action lines run full-width. The formatting is the meaning. 

INT. LIGHTHOUSE — DAWN

A bell rope swings in the gloom. WREN watches it.

                    WREN
              (quietly)
              It hasn't rung in three days.

She turns the lantern up.

Loom keeps the screenplay's spirit — characters in caps, dialogue indented under them, action lines as prose — but it adds the things a game or interactive show needs: choices, variables, and conditions. The result is a script that a director can read straight through and a runtime can execute.

How Loom looks

The smallest playable Loom file is three lines:

# hello

WREN
  Welcome.

That's a complete document. Reading it:

  • # hello — the document header. Every file starts with one. hello is the document's id.
  • A blank line — Loom uses blank lines as breathers, the way a screenplay does.
  • WREN at the left margin — a speaker. By convention speaker names are ALL CAPS.
  • The indented line beneath — what Wren says.

Indentation matters. The two-space indent under WREN is how Loom knows the line belongs to her, the same way the screenplay's center-tab does the same job visually.

The progression

Each numbered folder below is a single lesson. Open its readme.html, read the lesson, then open the .loom file in any text editor. The files are intentionally small — a few dozen lines each — so you can hold the whole story in your head while reading.

  2. your first Loom document — headers, tags, archetypes

  4. backlinks — [[target|display]]
  5. a tiny complete story — everything together

A word about the brackets

Loom uses a few symbols that look funny at first. The promise it makes — and keeps — is that each bracket has exactly one job. When you see one, you always know what it does.

Symbol Meaning Example
$x resolve — "what is this now?" $trust
@x static reference — "this thing exists in the project" @lighthouse
[[x]] backlink — "this prose mentions x" [[wren|Wren]]
<...> effect — a trigger, cue, or inline assignment <$trust += 5>
-- section header -- harbor_scene
* / + choice (once-only / sticky) * I'll help.
-> divert (jump to a section) -> harbor_scene
~ action line (do something — set a variable, fire an event) ~ var $trust := 30
> flavor / narrator prose > The wind picks up.

Don't memorise the table. Each symbol gets its own lesson.

How to read a lesson

Each lesson page follows the same shape:

  1. The idea. One paragraph saying what the lesson teaches.
  2. The story. The full text of the .loom file, inline so you don't have to switch windows.
  3. What you just learned. A short list of the moves the story used, so you can find them again later.
  4. Try this. A small change to make to the file. Editing the file teaches faster than reading does.

When in doubt, open lesson 1 and go forward in order.
