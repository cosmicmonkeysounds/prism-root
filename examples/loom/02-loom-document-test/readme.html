Lesson 02 — your first Loom document

Every .loom file begins with a document header: a # followed by an id. That's enough to make Loom recognise the file as a real document. After the header you can add an optional title in quotes and any number of archetype tags that say what kind of file it is.

The shape

# my_doc_id "An Optional Title" :archetype :other_tag

Things to notice:

  • The id is one word, lowercase, with underscores: harbor_intro, elena_meeting. No spaces.
  • The title is human-readable. It shows up in editors and bundle browsers, not in dialogue.
  • Tags say what kind of document this is. The big ones are :conversation, :character, :faction, :script, :film, :cutscene, :quest. Pick one or leave it off — an untagged document is treated as a generic conversation.

The minimum that runs

The shortest playable Loom file is just two lines:

# empty_scene

> A quiet morning.

Open lesson.loom. There are two documents stacked — when the runtime encounters the second # at the left margin it knows the first document is over and a new one begins.

What you just learned

  • # id "Title" :tag is the document header.
  • Multiple documents can sit in one file; each starts with its own #.
  • The tag is informational — Loom uses it to pick the right archetype- specific shape when you start using features like cast, knowledge, or cue.
Try this. Add a third document to lesson.loom: # my_third on a new line, followed by one indented flavor line underneath. The runtime will load all three.
