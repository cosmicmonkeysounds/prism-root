Lesson 13 — the ledger

Loom keeps an automatic diary of everything that happens — every section the player visited, every choice they took, every event the story fired. That diary is called the ledger, and you can ask it questions from inside any condition.

The four most useful questions

Question Answers
played(section) Has the player been to this section at least once?
visits(section) How many times have they been there?
chose(label_or_section) Did they ever pick a choice with that label, or from that section?
since(event) How long since the named event last fired? (next lesson)

Using them

Each predicate plugs into a condition. They're just expressions:

* Try again. if played(intro) and not chose("help me")

-- meeting if visits(meeting) < 3

after played(harbor)
  WREN
    We met at the harbor, didn't we?
Note on guards. Loom puts if guards on sections and choices, not on individual dialogue lines. To gate a single line, wrap it in an after <cond> block (lesson 15) or move it to its own guarded section.

A small worked example

Open lesson.loom. It uses visits(...) to detect a returning visitor and chose(...) to remember a previous answer. The whole point: the writer never has to set a variable. The ledger remembers automatically.

Variables vs the ledger

When to use
variable ($trust) A value that needs to be set, raised, lowered, and read.
ledger query "Did this happen?" — anywhere you'd otherwise add a boolean variable that you only ever set to true.

A common beginner mistake is writing ~ var $met_wren := true in the meeting scene and then later checking if $met_wren. The ledger already knows you were in meeting — use if played(meeting) instead.

What you just learned

  • The runtime keeps an append-only ledger of every visit, choice, and event.
  • played(X), visits(X), chose(X) are queries against that ledger.
  • Prefer the ledger to a boolean variable when the question is just "did this happen?"
The label match. chose("help me") matches the exact text the player saw. It's case-sensitive. If your menu used the capitalisation "Help me", write that. Whitespace is collapsed on both sides, so a stray space is forgiven.
