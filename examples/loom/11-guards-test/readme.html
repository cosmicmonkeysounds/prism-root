Lesson 11 — conditions on choices

A guard is a "show this only if…" condition you can stick on a choice, a section, or a block. The runtime evaluates the condition at the moment of decision and hides the line if the condition is false.

The shape

* Tell me the secret. if $trust > 50

Everything before if is the choice label. Everything after if is the condition. Spelling it out:

  • * — opens a once-only choice.
  • Tell me the secret. — what the player would see in the menu.
  • if — the gate keyword.
  • $trust > 50 — the condition. If it's true, the choice appears; if it's false, the player never sees it.

What conditions can look like

The right-hand side is an expression. Common shapes:

Shape Meaning
$xtrue if x is set and non-zero / non-empty
$x == 5x is exactly five
$x > 50x is more than fifty
$x <= 10x is at most ten
not $xx is unset, zero, false, empty
$a and $bboth true
$a or $beither true

Guarded sections

You can also gate a whole section:

-- secret if $trust > 50

WREN
  Listen close.

If the playhead would fall through into secret and the guard is false, Loom skips that section and tries the next one.

What's truthy?

Loom uses the same intuition you'd expect from English:

  • true, any non-zero number, any non-empty string, any non-empty list — truthy.
  • false, 0, the empty string, nil, an empty list — falsey.

So if $met_wren is shorthand for "if you've ever met Wren".

What you just learned

  • if <expression> on a choice line hides the option when the expression is false.
  • The same syntax works on section headers (-- name if <expression>).
  • Comparison operators: ==, !=, <, <=, >, >=. Boolean operators: and, or, not.
One operator gotcha. Use == for comparison — two equals. A single = is for declaration and binding (you'll see it in let next lesson). Loom catches if $x = 5 as a parse error rather than letting it silently assign.
Try this. Add a fourth choice in lesson.loom that's gated on if $trust >= 100. You won't see it because trust never reaches 100 in this story — that's the whole point of guards.
