# Loom v3 examples

Reference `.loom` projects. Each subdirectory is a self-contained
multi-file project rooted at `main.loom`. Used by `loom-runtime`
integration tests and as authoring tutorials.

The lesson corpus is rebuilt from scratch as v3-native — typed slots,
multi-file projects, the reactive layer, the live layer — once the
parser is in. Phase 1: empty.
