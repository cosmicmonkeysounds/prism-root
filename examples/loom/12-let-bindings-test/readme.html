Lesson 12 — let bindings

In the last lesson you wrote a guard like if $trust > 50. If you find yourself writing that same condition in three places, it's time for a let binding: a name for the expression you can reuse everywhere it's true.

The shape

At the top of a document, before any sections:

let trusted   = $trust > 50
let in_danger = $health < 30
let armed     = $weapon and $ammo > 0

And then anywhere in the story:

* Tell me the secret. if $trusted
* Run!  if $in_danger

$trusted is now a variable just like any other — except it's computed from $trust rather than set by you. Whenever $trust changes, $trusted updates the next time any line reads it.

How let differs from var

var let
You set its value Yes — with ~ $x := v No — Loom computes it from a formula
It stays up to date Only when you write to it Automatically, when the things it depends on change
It serializes in saves Yes (it's a stored value) No (it's re-derived on load)
Used for… "trust", "health", "town" "trusted", "in_danger", "armed"

Naming bindings well

The whole point of a let binding is that it reads like a sentence.

* Hide the body. if $can_act_unseen and $night

* Confess.       if $witness_present and not $bribed

If the binding name doesn't make the choice line easier to read, you don't need the binding.

Bindings that depend on other bindings

Bindings see earlier bindings, so you can layer them:

let trusted   = $trust > 50
let well_lit  = $time < 21 or $lantern_lit
let it_is_safe = $trusted and $well_lit

What you just learned

  • let name = <expression> declares a derived variable.
  • Loom recomputes lets whenever any var they depend on changes.
  • Use lets to name conditions so guards read like English.
  • Lets can depend on earlier lets in the same document.
Phase note. Today Loom recomputes all bindings eagerly on every var write. That's perfectly fine for hundreds of bindings; future phases will swap in incremental recomputation for shows with thousands. Nothing changes from the writer's perspective.
Try this. Add a binding let very_trusted = $trust > 90 and a choice gated on if $very_trusted. The story already raises trust to 75, so the new choice will still be hidden — proving the binding works.
