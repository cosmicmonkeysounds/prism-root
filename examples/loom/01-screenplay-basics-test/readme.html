Lesson 01 — what a screenplay is

Before Loom adds a single feature of its own, it sits on top of a few hundred years of theatre and film convention. This lesson is for writers who have never written one and would like the vocabulary. If you have written a script before, skim and move on.

The five line types

A traditional screenplay is built from five kinds of line. The layout tells you which is which — no labels needed. 

INT. LIGHTHOUSE — DAWN                          ← scene heading

A bell rope swings in the gloom. WREN watches  ← action line
it from the doorway.

                    WREN                        ← character name
              (quietly)                         ← parenthetical
              It hasn't rung in three days.     ← dialogue

She turns the lantern up.                       ← action line

The roles, in order:

  • Scene heading ("slugline"). Tells the reader where and when the next chunk happens. INT. = interior, EXT. = exterior, then the place, then the time of day.
  • Action line. Prose describing what is happening on screen or stage. Present tense. One thing per paragraph.
  • Character name. ALL CAPS, centered. The performer about to speak.
  • Parenthetical. A tiny stage direction tucked under the name. Use sparingly — let dialogue do the work.
  • Dialogue. Indented under the name. What the character says.

Why we tell you this

Loom keeps every one of those five and adds three more (choices, variables, conditions). If you read a .loom file with a pencil over the funny symbols, what's left should look like a screenplay.

The same scene in Loom

Open lesson.loom next to this page. The whole file:

# lighthouse_dawn

cast WREN
  .label "Wren the Keeper"

-- dawn

> INT. LIGHTHOUSE -- DAWN

> A bell rope swings in the gloom. Wren watches it from the
> doorway.

WREN { quietly }
  It hasn't rung in three days.

> She turns the lantern up.
One quirk to know. Inside .loom files Loom is ASCII-only — em-dashes, smart quotes, and the like don't lex yet. Write -- instead of — and " instead of ". The HTML around the file can use whatever Unicode it likes.

Mapping it back:

  • # lighthouse_dawn — the document header. New in Loom.
  • cast WREN — declares who can speak. New in Loom.
  • -- dawn — a section, the unit the runtime plays. Think of it as a scene heading you can jump to. New in Loom.
  • > ... — flavor / action lines. The > replaces "this is action, not dialogue".
  • WREN at the left margin — the character about to speak.
  • { quietly } — the parenthetical. Curly braces instead of round ones, but the meaning is the same.
  • The indented line — the dialogue.

What you just learned

  • A screenplay's five line types: scene heading, action, character, parenthetical, dialogue.
  • Loom keeps them all, prefixing action lines with > and writing parentheticals as { quietly } instead of (quietly).
  • Two things Loom adds even at this stage: a document header (#) and a section header (--).
Try this. Open lesson.loom and add a second dialogue line under Wren — just another indented sentence below the existing one. It will play as the same dialogue beat, two lines long.
