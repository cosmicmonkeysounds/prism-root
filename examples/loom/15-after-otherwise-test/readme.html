Lesson 15 — after / otherwise

Guards (lesson 11) hide a single line. after blocks hide a whole chunk of script — and let you pair it with an otherwise chunk that plays when the condition is false. They're Loom's "if / else" for narrative.

The shape

after $trusted
  WREN { warm }
    Come in. Stay a while.
otherwise
  WREN { wary }
    State your business.

How it runs:

  1. The playhead reaches after $trusted.
  2. It evaluates the condition.
  3. If true, the indented block under after plays.
  4. If false, the indented block under otherwise plays instead.
  5. Either way, the playhead resumes after the whole pair.

The otherwise is optional. after alone is just "play this block only if true; skip otherwise."

When to use it vs a guarded section

Pattern Use for
after / otherwise A two-way fork inside a single scene.
Guarded section (-- foo if ...) Whole scenes you want to skip entirely.
Guarded choice (* foo if ...) One option in a menu.

Several blocks in a row

You can stack after blocks for cascading conditions — write them as separate pairs, not as a single chain:

after $morning
  WREN
    Tea's still warm.

after $afternoon
  WREN
    Sun's pleasant.

after $evening
  WREN
    Time to head in.

Each pair stands on its own. If two are simultaneously true, both play. For one-out-of-many, see match in lesson 17.

What you just learned

  • after <expression> introduces a conditional block.
  • otherwise after an after is its else half.
  • Both bodies are indented under their keyword.
  • Use after for inside-the-scene forks; use guarded sections for skip-the-whole-scene forks.
The reading rule. If you can sketch the scene's two versions on the same imaginary page, use after / otherwise — the alternative bodies sit right next to each other in the source, which makes the contrast easy to see.
