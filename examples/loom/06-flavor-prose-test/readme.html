Lesson 06 — flavor and stage prose

Not every line in a script is dialogue. Sometimes you need to describe the setting, narrate an action, or whisper an aside to the reader. In a screenplay those are action lines. In Loom they're flavor lines, marked with a leading >.

The shape

> The bell rope swings in the gloom.
> Wren watches it from the doorway.

WREN
  Three days.

> She turns the lantern up.

Each > line is one beat of narration. The runtime surfaces it as a separate frame (Frame::Flavor) so the host can render it differently from dialogue — italicised, dimmer, smaller text, however the player's UI distinguishes them.

Why a different symbol?

In a traditional screenplay you'd write the same prose without any prefix because the layout (full-width, no character above it) tells you it's action. Loom uses sigils instead of layout, so the > is what says "this isn't a speaker, it's narration".

The mental rule:

  • If the audience would hear a performer say it, it's dialogue (SPEAKER + indented line).
  • If it's a stage direction, scene description, or narrator aside, it's flavor (>).

Inline flavor inside a scene

You can interleave flavor and dialogue freely:

-- harbor

> A grey morning. The tide is out.

WREN
  Late again.

> She kicks a stone into the water.

WREN { soft }
  Almost.

What you just learned

  • > at the start of a line means "narrator / stage direction".
  • Flavor lines surface as their own frame so the host can style them distinctly.
  • Flavor and dialogue mix freely — write them in whatever order reads best.
Try this. Add a stage direction between Wren's lines in lesson.loom — for example, > A gull cries. Watch the playhead emit it as a Flavor frame, between the two Dialogue frames.
